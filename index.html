About Us

Why VIBHOR Exists

VIBHOR (meaning “splendour” in Sanskrit) is a single, organised journey through 120 heritage stories — ten per category, in every region. Instead of making you search, we lay out the entire country as four regions × twelve categories × every state — so you can simply pick a door and walk in.

Every story is a real place or tradition with its own history, features and cultural importance, linked to its Wikipedia reference — and every page streams related videos straight from YouTube, so the heritage doesn't just sit on a page: it moves, it dances, it cooks, it sings.

This is a fan-made, educational curation. Images are stock and illustrative placeholders.

Good to Know

Frequently Asked Questions

VIBHOR is an immersive, frontend-only heritage portal. It organises Indian culture into four regions and twelve categories, with 120 curated stories — each with history, key features, cultural importance, a photo gallery, a Wikipedia reference and a live stream of related YouTube videos.

The four cultural regions — North (UP, Rajasthan, Punjab, Himachal, Uttarakhand, Delhi, MP, J&K), South (Tamil Nadu, Karnataka, Kerala, Andhra Pradesh, Telangana), East (West Bengal, Odisha, Bihar, Jharkhand, Assam, Chhattisgarh) and West (Maharashtra, Gujarat, Goa). The interactive map covers all 34 states and UTs, each coloured by its cultural region.

Every detail page calls a YouTube search API with the exact name of the cultural item (for example, “Brihadeeswarar Temple”). The JSON response is parsed for video IDs and thumbnails, and the results appear as a clickable gallery that plays inside a modal using standard YouTube embed iframes. If the service is unreachable, a graceful fallback with a direct YouTube link is shown.

Names, places, histories and cultural facts are researched and linked to their Wikipedia articles, which you can open from every page. Short descriptions are written in a narrative style for a portal, so for academic use please follow the reference links.

The images are stock/illustrative placeholders sourced from open web searches, and the site is built with plain HTML, CSS and JavaScript — no frameworks. Feel free to study and adapt the code for your own learning projects; credit the original photographers and publishers where images are used.
